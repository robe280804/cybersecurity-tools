# Tool esterni richiesti dagli script (il "requirements.txt" dei binari).
#
# Gli script NON includono questi tool: li orchestrano se presenti nel PATH.
# Un tool mancante viene saltato con un warning, non blocca la pipeline — ma
# lo step che lo usa produce meno risultati (o nessuno).
#
# Installali con:   ./install-tools.sh            (core)
#                   ./install-tools.sh --all      (core + docker + opzionali)
#                   ./install-tools.sh --list     (mostra cosa manca)
#
# Formato (una riga per tool, campi separati da '|'):
#   nome | categoria | metodo | spec
#     categoria: core     -> pipeline recon (step 1-6)
#                docker   -> solo per recon/docker-configuration
#                optional -> suggeriti negli execute.md, non orchestrati
#     metodo:    apt | go | script | manual
#     spec:      pacchetto apt, module path Go, o nota per manual/script
